# Universal Focus Privacy Policy

Universal Focus is a local-only Chrome extension. It does not collect, transmit, sell, or share webpage text, search queries, messages, passwords, browsing history, or typed content.

## What is stored

The extension stores only user-selected settings in Chrome's local extension storage:

- Focus indicator color and duration
- Whether tiny fields and password fields should be ignored
- Optional per-domain preferences such as `search` or `chat`

## What is processed temporarily

When the user presses the configured shortcut, Universal Focus temporarily inspects the current page's DOM to identify visible editable fields. This information is used only to choose which field to focus and is not saved or sent anywhere.

## Third parties

Universal Focus has no backend, analytics, advertising, external API, or third-party data processor.
